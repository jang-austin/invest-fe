sitemap.xml / robots.txt 작성 후 배포

Q. 각각 무슨 역할을 하는지?
sitemap.xml
사이트에 어떤 페이지(URL)가 있는지, 언제 수정됐는지를 검색엔진에 알려주는 "페이지 목록표"입니다. 크롤러가 새 페이지를 빠르게 발견하도록 돕습니다.
robots.txt
크롤러에게 "이 경로는 수집해도 됨/안 됨"을 알려주는 안내 파일입니다. sitemap.xml의 위치도 여기에 적어둘 수 있습니다. 접근을 강제로 막는 보안 장치는 아니므로, 민감한 정보를 숨기는 용도로 쓰면 안 됩니다.

Q. SEO용 title, description 설정도 해주는 게 좋다?
title
검색 결과에 파란 제목으로 표시되며, 구글이 페이지 주제를 파악하는 핵심 단서입니다. 페이지마다 고유하게, 핵심 키워드를 앞에 두고 50~60자 안팎으로 쓰는 것이 좋습니다.
description (meta)
검색 결과 제목 아래 요약문으로 쓰이는 경우가 많습니다. 순위에 직접 영향을 주기보다 클릭률에 영향을 줍니다. 120~160자 정도로 페이지 내용을 요약해 적습니다.
왜 필요한가
설정이 없으면 구글이 본문에서 임의로 제목과 요약을 뽑아 의도와 다르게 보일 수 있습니다. 함께 lang, canonical, Open Graph(og:title, og:description) 태그도 넣어두면 좋습니다.
